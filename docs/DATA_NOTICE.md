# Data notice

This lightweight repository does not redistribute large source datasets or model weights.

- TorchSig signals are generated from the frozen source/configuration code.
- Covertype is available from UCI/scikit-learn; frozen index panels are retained, the large cache is omitted.
- CIFAR-10 and CIFAR-10-C source archives are omitted; download/checksum scripts are retained.
- mini CURE-OR image archives and ConvNeXt weights are omitted; official metadata, frozen split manifests and canonical checksums are retained.

Compact tables are derived outputs and are included solely to verify manuscript-facing claims and rebuild figures. See `evidence/full_evidence_manifest.json` for the omitted complete archive hash.
